# AIoT 设备运维 SOP

## 高温告警处理流程

1. 查询设备状态，确认当前温度、在线状态、电量和最近心跳时间。
2. 查询最近 24 小时历史告警，判断是否为连续告警。
3. 检查设备部署环境，确认是否存在热源靠近、通风受阻或冷库异常升温。
4. 检查散热口和风扇，清理遮挡物和灰尘。
5. 若温度持续高于 80 摄氏度，创建运维工单并标记优先级 P2。
6. 若温度高于 90 摄氏度或设备同时离线，升级为 P1 并安排现场处理。

## 离线告警处理流程

1. 查询设备最后在线时间。
2. 检查电量是否低于 20%。
3. 检查现场网络、网关供电和 SIM 卡/以太网连接。
4. 若离线超过 30 分钟，创建工单并安排巡检。

## 工单内容要求

工单需包含设备编号、告警类型、告警等级、可能原因、建议处理步骤和是否需要现场处理。
