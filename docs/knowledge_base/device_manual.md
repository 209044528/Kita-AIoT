# 冷链温控网关 A-01 设备说明书

## 设备用途

冷链温控网关 A-01 用于采集冷库区域温度、设备电量和通信信号，并通过 MQTT 上报运行状态与告警。

## 关键阈值

- 正常温度范围：-20 到 45 摄氏度。
- 高温预警阈值：80 摄氏度。
- 严重高温阈值：90 摄氏度。
- 低电量阈值：20%。
- 心跳周期：60 秒。

## 常见状态字段

- `status`: `online` 表示在线，`offline` 表示离线。
- `battery_level`: 电池电量百分比。
- `temperature`: 当前设备内部温度。
- `signal_strength`: 通信信号强度，单位 dBm。

## 高温保护建议

当设备温度超过 80 摄氏度时，应检查散热口、风扇、供电电压和部署环境温度。若超过 90 摄氏度或连续 3 次上报高温，应创建 P1/P2 工单安排现场处理。
