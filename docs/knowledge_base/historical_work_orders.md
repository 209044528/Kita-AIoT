# 历史工单样例

## WO-20260618-001 冷链温控网关高温

- 设备：device-001
- 告警：temperature_high
- 原因：散热口被保温材料遮挡。
- 处理：移除遮挡物，清理散热口，观察 30 分钟后温度恢复正常。
- 经验：同类告警应优先检查散热通道和部署位置。

## WO-20260619-004 边缘采集器离线

- 设备：device-003
- 告警：device_offline
- 原因：现场交换机端口异常导致设备无法连接 MQTT Broker。
- 处理：更换交换机端口并重启采集器。
- 经验：离线告警需同时检查电量、供电和网络链路。

## WO-20260621-002 产线振动传感器连续预警

- 设备：device-002
- 告警：vibration_high
- 原因：传感器固定螺栓松动。
- 处理：重新固定传感器并校准安装方向。
- 经验：振动告警应检查传感器安装状态和产线负载变化。
