# 故障排查手册

## temperature_high

可能原因：

- 散热口被遮挡或积尘。
- 设备风扇故障。
- 部署环境温度过高。
- 设备靠近压缩机、电源柜等热源。
- 温度传感器读数异常。

建议动作：

- 查询设备状态和最近历史告警。
- 检查现场温度和设备安装位置。
- 清理散热口，检查风扇是否转动。
- 连续告警时创建工单。

## device_offline

可能原因：

- 设备断电或低电量。
- 网络中断。
- MQTT Broker 地址或认证配置错误。
- 设备采集进程异常退出。

建议动作：

- 查询最后在线时间。
- 检查电量和现场供电。
- 检查网关网络连通性。
- 必要时重启设备或安排现场巡检。

## vibration_high

可能原因：

- 产线设备轴承磨损。
- 固定螺栓松动。
- 设备负载异常。
- 传感器安装位置松动。

建议动作：

- 查询最近振动告警频率。
- 对比设备温度和运行工况。
- 检查机械固定和轴承状态。
- 连续告警时创建 P2 工单。
